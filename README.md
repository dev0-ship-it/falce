# Scythe Mod

A small Fabric mod for Minecraft 1.21.1 that adds a netherite scythe.

## Features

- Fireproof netherite-based weapon with sword-style attack attributes.
- Added to the Scythe Mod creative tab with Sharpness VI, Unbreaking V, Mending V, and Fire Aspect III.
- Uses the vanilla iron hoe icon as a visual placeholder for the scythe.

## Build

Use Java 21 and Gradle, then run `gradle build`. The mod jar will be created in `build/libs/`.
